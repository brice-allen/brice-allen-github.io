How this portfolio works

this site has no images. i have aphantasia — when i close my eyes, nothing is there. no apple, no beach, no faces. what i have instead is structure: everything connected to everything, a web you can pull on from any point and feel the whole thing move.

so this is a portfolio built the way i actually think. the work below is cut into patches and sewn down. pull a thread above and watch what holds together.

tower — a house that runs on containers

unraid · 44 containers · traefik + authelia · gluetun/wireguard · adguard → unbound · borgmatic

the home server. media, dashboards, dns that trusts no upstream (unbound talking straight to the roots), single sign-on at the front door, segmented networks behind it, and encrypted backups buried offsite nightly — backups that have actually been restored, which is the only kind that count.

it is opinionated infrastructure for two people and a dog, maintained like it serves ten thousand.

stack-health.sh

bash · v17.6 and counting · proper git history

a shell script that grew a personality. container liveness, traefik route discovery via labels, dns sanity, vpn egress checks, timed reports. proof that the best monitoring tool is the one you actually read.

cryptkeys.rip — music made of ghosts

python · dsp · fastapi · docker · a graveyard with a ui

audio distilled into structural fingerprints — envelopes, rhythm, spectral contours — and then the body is deleted. a mortician schedules deaths for .crypt files and issues ascii death certificates. a resurrector raises them later as something adjacent: recognizably the same skeleton, wearing different air.

started as a cli, now a full web app with decay models and a graveyard you can walk.

loudspeakers, from filament up

printed spherical enclosures around little dayton 3.5s — port geometry, damping, print orientation all argued over. open-baffle experiments with full-range paper. a two-way build with a 10-inch woofer that owes an apology to devore.

bought for ten dollars with dc on the outputs. diagnosed, recapped, brought back. vintage gear is the original open source: schematics in the manual, parts you can see, failure modes you can reason about with a meter and patience.
